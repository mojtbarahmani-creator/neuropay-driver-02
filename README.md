# نوروپی (NeuroPay)

نسخه نمایشی اندروید برای آزمایش رابط کیف پول.

## ساخت APK
در GitHub به بخش Actions بروید و اجرای Build NeuroPay APK را انتخاب کنید.
پس از پایان موفق، فایل APK را از بخش Artifacts دریافت کنید.

## توجه مهم
این برنامه صرفاً نمایشی است. موجودی واقعی نیست و به بانک یا سامانه پرداخت متصل نیست.
پرداخت‌ها و درخواست برداشت واقعی انجام نمی‌شوند. برای استفاده مالی واقعی،
به سرور امن، احراز هویت، کنترل تراکنش و اتصال قانونی به ارائه‌دهنده پرداخت نیاز است.
