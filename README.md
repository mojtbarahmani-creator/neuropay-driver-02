# نوروپی (NeuroPay) — پروژهٔ آزمایشی Android

اپلیکیشن بومی اندروید با Kotlin و رابط فارسی/راست‌چین.

## نیازمندی‌ها
- Android Studio نسخه‌ای که Android Gradle Plugin 8.6.1 را پشتیبانی کند
- JDK 17
- Android SDK Platform 35

## باز کردن و اجرا
1. ZIP را استخراج کن.
2. در Android Studio گزینهٔ **Open** را بزن و پوشهٔ `NeuroPay` را انتخاب کن.
3. صبر کن Gradle Sync کامل شود.
4. یک شبیه‌ساز یا گوشی اندرویدی انتخاب کن و **Run** را بزن.
5. برای ساخت APK آزمایشی از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کن.

فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## ساخت APK با GitHub Actions
پروژه را در یک مخزن GitHub بارگذاری کن. از بخش **Actions** گردش‌کار Android Debug APK را اجرا کن. فایل APK به‌صورت artifact بارگذاری می‌شود.

## هشدارهای مهم
- این صرفاً نمونهٔ رابط کاربری است؛ پرداخت و برداشت واقعی انجام نمی‌شوند.
- موجودی و تاریخچه فقط در حافظه هستند و با بستن برنامه پاک می‌شوند.
- پرداخت آفلاین واقعی به طراحی ضد دوباره‌خرج‌کردن، کلیدهای امن، شناسهٔ یکتای تراکنش، همگام‌سازی سرور و سیاست حل تعارض نیاز دارد.
- برداشت بانکی واقعی به سرور امن، تأیید مالکیت حساب/شبا، کنترل‌های ضدتقلب و اتصال مجاز به ارائه‌دهندهٔ بانکی نیاز دارد.
- برای استفاده با پول واقعی، الزامات قانونی و مجوزهای لازم در ایران باید با شریک مالی/حقوقی واجد صلاحیت بررسی شوند.
